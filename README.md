# Spectral - My first slackbot!

This is my very first slackbot. It's kind of useless, but it has a space theme to it at least? 
Oh, and it's named after stellar spectral types.

## Tech stack

## Commands

- /spectral-help - Help using Spectral!
- /spectral-about - About Spectral!
- /spectral-spacefacts - Get a space fact!
- /spectral-uselessfacts - Get an entirely useless fact
- /spectral-duckpic - Get a random picture of a duck for free!

## APIs used

- /spectral-spacefacts: <https://api.bootprint.space/fact/>
- /spectral-uselessfacts: <https://uselessfacts.jsph.pl/api/v2/facts/random?language=en>
- /spectral-duckpic: <https://random-d.uk/api/random>
